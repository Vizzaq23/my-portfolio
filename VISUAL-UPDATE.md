# Mario world art direction

Branch: `feat/3d-world-polish`.

All five world backgrounds use a Super Mario 3D World theme. Later refinements simplify the overworld, map and airship into more restrained game scenery. The shared visual language includes rounded sculpted hills, saturated colors, soft highlights, glossy green pipes, generous grass lips, warm gold collectibles, red spotted mushrooms and brass-trimmed airships. Reference: [Nintendo's official game page](https://www.nintendo.com/sg/switch/auzp/3dworld/index.html).

The foreground now uses matching beveled front-facing skill blocks, rounded grass platforms, gold coins, glossy open pipes, a sculpted castle, waving red flag, cloud puffs and a shaded sun. The existing pixel runner remains pixel art and runs/jumps through the level. Palette and material changes also tie the project, profile, experience and contact panels into the scenery. Project identities, screenshots and destinations are preserved; the later career-copy refinements are documented below.

Images were created with the **built-in image generation tool**, then encoded as WebP for the site. Original generated PNGs remain in the generation directory. All consumed files are in `public/worlds/`. Castle transparency is preserved. No API or CLI image generation was used.
