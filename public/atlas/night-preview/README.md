# Night title motion study

Open `/atlas/night-preview/index.html`. Standalone Canvas 2D study, separate from the existing 3D intro and live homepage. Start/Skip link directly to the current homepage.

Shared spring-smoothed wind drives clipped image-row warps for leaves, grass, poster and flag. Water uses narrow displacement bands and shimmer fragments. Lighthouse and lamp lights are additive overlays. Pause freezes scene time; OS reduced-motion starts paused, with an explicit Play override. No audio or dependencies.

This is an art-driven approximation, not cloth/fluid physics. The flattened illustration includes static lighting; its original lighthouse beam remains under the animated overlay. Crop boundaries and baked props limit movement. Next production pass should separate foreground foliage, cloth, water, character and lighting into authored layers. Character idle/boat motion are not implemented here.

`night.png`: generated concept from the approved November 12 2026 night palette exploration, source `exec-13d14b31-40d2-4853-9bbc-8fe064f4f83c.png`. Contains requested One Piece/Mario-inspired fan elements; not a claim of ownership of those characters.
